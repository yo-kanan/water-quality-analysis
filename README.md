# 💧 Water Quality Analysis

## 📌 Project Overview
This project analyzes water quality data to determine whether water is safe for drinking. It uses data preprocessing and exploratory data analysis techniques to understand factors affecting water potability.

---

## 🛠 Tools & Technologies
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Jupyter Notebook  

---

## 📂 Dataset
Dataset sourced from Kaggle containing various chemical properties of water samples used to determine potability.

---

## 🔍 Project Workflow
- Data Cleaning and Handling Missing Values  
- Exploratory Data Analysis (EDA)  
- Statistical Summary of Features  
- Data Visualization  
- Identifying key factors affecting water quality  

---

## 📊 Key Insights
- Analyzed chemical properties affecting water safety  
- Identified missing value patterns in dataset  
- Compared potable vs non-potable water samples  
- Visualized distribution of key parameters  

---

## 🚀 Objective
To analyze water quality data and understand the key factors that determine whether water is safe for human consumption.
